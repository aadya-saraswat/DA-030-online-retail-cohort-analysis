# Analytical Visuals & Charts

This folder contains the primary visual deliverables generated from the cohort analysis notebook:
- `cohort_retention_heatmap.png`: Monthly cohort retention matrix (%) across 12 cycles.
- `monthly_active_customers.png`: Stacked bar chart showing new vs. repeat customer volumes.
- `customer_spend_trajectory.png`: Average customer spend trajectory across the cohort lifetime.
