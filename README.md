# DA-030: Online Retail Cohort & Repeat Purchase Analysis

## Project Overview
This project performs customer retention and repeat purchase behavior analysis using transactional data from an online retail platform. By tracking user behavior across cohorts, we quantify customer retention rates over time and evaluate spend dynamics across the customer lifecycle.

## Tech Stack & Libraries
- **Environment:** Jupyter Notebook / Google Colab
- **Language:** Python 3
- **Data Manipulation:** `pandas`, `numpy`
- **Visualization:** `matplotlib`, `seaborn`
- **Data Source:** UCI Machine Learning Repository (Online Retail Dataset, ID: 352 via `ucimlrepo`)
